# Security Policy

## Supported versions

Security fixes go into the latest stable release. If you're on an older version, update first and check whether the problem is still there.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Use **Security → Report a vulnerability** on the [repository page](https://github.com/hiall-fyi/tado_ce/security/advisories/new) so the report stays private until a fix is out.

A useful report says what you found, how to reproduce it, and which Tado CE and Home Assistant versions you were running. You'll get a reply once it has been read, and a fixed release is credited to you unless you'd rather it wasn't.

## Keep these out of public issues and logs

When you file an ordinary bug report, remove or replace:

- Your Tado login, authorisation codes and any access or refresh tokens.
- The HomeKit setup code printed on your Internet Bridge.
- Your home address, home and zone IDs, and device serial numbers.

Debug logs aren't redacted, so read them through before posting.
